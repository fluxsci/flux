# V0.2.0 dependency disposition

Observed 2026-09-21. Baseline audit at c289627 had32 affected dependency nodes (18 high,12 moderate,2 low), not32 unique vulnerabilities. The final `npm audit --json` reports0 findings across611 dependency entries. A fresh `npm ci` completed in `/tmp/flux-v020-dependencies-2`; the running checkout’s dependency tree was not modified. All upgrades stayed within existing declared major ranges; CSS Tree and a direct patched XML parser were added for the accepted passive-SVG and DOCX contracts. No `audit fix --force` or severity suppression was used.

Raw evidence: `test-results/v020/audit-before.json`, `test-results/v020/audit-final.json`. The table accounts for every originally affected node and its installed lookup path; a via-only entry inherits the linked descendant advisory. An absence of an npm finding is not a claim that all possible application vulnerabilities are absent.

Electron moved from the locked43.x baseline to43.7.3. The43 branch is retained within the [upstream latest-three-major support policy](https://www.electronjs.org/docs/latest/tutorial/electron-timelines); actual native/package tests qualify the update separately. PDF.js is6.3.289. [Mozilla’s PDF.js advisory](https://github.com/mozilla/pdf.js/security/advisories/GHSA-hq66-cqwq-w95j) identifies a scripting/CSP-dependent path; the baseline was affected by version but an exploit in Flux was not established. Reader has no scripting manager, and the current inert-script/native fixtures separately verify its supported behavior.
